# E.I.L — מיפוי תוכן ראשוני

## מטרת המיפוי

18 הפרקים הם שכבת הידע הראשית. כל פרק מקבל קטגוריה ראשית, קטגוריות משניות, נושאים וקשרים לפרקים אחרים. המיפוי הזה יהיה הבסיס לקליטת קבצים עתידיים ולהשוואת חפיפות ופערים.

## חמש קטגוריות-העל

| קטגוריה | משמעות | פרקים מרכזיים |
|---|---|---|
| הגוף והמערכת הפיזית | גוף, מערכות, סביבה וכאב | 1, 2, 3, 9, 16 |

## רצף הלמידה

**התבוננות → כלי → מערכת → מוח → תדר → שינוי → זהות → רגש → מציאות → עקרונות → מימוש → משמעות → אינטגרציה → זהות מסונתזת**

זהו הרצף הנרטיבי. הוא שונה מהקטגוריות: קטגוריה אומרת *מה הנושא*, והרצף אומר *למה הפרק נמצא שם*.

## התאמת קבצים עתידיים

כאשר יועלה קובץ חדש, לא נוסיף אותו מיד כפרק חדש. קודם נזהה:

1. **נושא ראשי** — על מה הקובץ באמת מדבר.
2. **נושאים משניים** — מושגים שחוזרים או תומכים בנושא הראשי.
3. **התאמות** — אילו מהפרקים 1–18 כבר מכסים את התוכן.
4. **חפיפה** — תוכן שכבר קיים, עם דירוג חוזק התאמה.
5. **פער** — מידע חדש שאינו קיים או קיים באופן חלקי.
6. **סתירה** — טענה חדשה שסותרת טענה קיימת; לא נדרוס תוכן אוטומטית.
7. **מקור** — מאיפה הטענה הגיעה, כדי שנוכל להציג מקור/אמינות בנפרד מהטקסונומיה.

## סוגי התאמה

- `exact` — כמעט אותו נושא/רעיון.
- `related` — נושא קשור שמוסיף הקשר.
- `extends` — הקובץ החדש מרחיב פרק קיים.
- `contradicts` — קיימת סתירה שדורשת בדיקה.
- `new` — נושא חדש שאינו מכוסה מספיק.

## עיקרון חשוב

המיפוי אינו קובע שהטענות בפרקים הן עובדות מדעיות. הוא מסווג **את התוכן כפי שהוא מופיע בחומר המקור**. בהמשך אפשר להוסיף לכל טענה שכבת `evidence` נפרדת: מדעי / מחקרי / פילוסופי / מסורתי / השערה / תרגול אישי.
