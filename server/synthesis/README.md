# Server / Synthesis

Owns derived understanding built on top of preserved sources.

Future services belong here when extracted from thin `/api` route adapters:
- topic/relationship matching
- knowledge graph construction
- cross-source insights
- evidence gathering
- mentor retrieval and grounded synthesis
- contradiction/uncertainty handling

Rules:
- Every asserted derived insight should carry evidence references when possible.
- Synthesis never replaces canonical source text.
- Retrieval, ranking, interpretation, and presentation are separate responsibilities so each can evolve independently.
